Nexus3D Studio

A Mobile-First 3D Modeling, Mesh Editing & Animation Web Application

Nexus3D Studio is a browser-based 3D creation workspace built with React, TypeScript, and Three.js. Designed with a fullscreen landscape interface, it provides tools for creating, editing, transforming, and animating 3D objects.

Features

- 3D Scene Editor
- Primitive Object Creation
- Object Selection and Hierarchy
- Move, Rotate, and Scale Gizmos
- Vertex, Edge, and Face Editing
- Mesh Subdivision and Loop Cutting
- Extrusion and Mesh Smoothing
- Manual Bone and Auto-IK Tools
- Animation Timeline and Keyframes
- Camera and Lighting Controls
- HDRI Environment Presets
- GLTF/GLB and OBJ Import
- Project Save and Load

Technology Stack

- React 19
- TypeScript
- Three.js
- Vite
- Tailwind CSS
- Lucide React

Getting Started

Requirements

- Node.js
- npm

Installation

git clone https://github.com/json091390-ai/Nexus3D-Studio.git
cd Nexus3D-Studio
npm install
npm run dev

Production Build

npm run build
npm run preview
